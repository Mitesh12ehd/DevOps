uptime:
    - give time from when machine is up
    - give user logged in
    - and system load average
    
    16:05:54 up  4:01,  1 user,  load average: 0.17, 0.38, 0.34

    - 16:05:54: System time 
    - up  4:01: uptime
    - 1: 1 user logged in 
    - 0.17: 1 minute load 
    - 0.38: 5 minute load
    - 0.34: 15 minute load

    Load average:
        - Load average represents the average number of tasks that are:
        - Running or waiting for CPU time.

sudo:
    - super user do
    - it execute command with administrator permissions
    - sudo is group
    - any user which is part of sudo group can execute command with sudo level permissions
    - id command shows current user is part of sudo group or not

jobs:
    - used to display jobs (processes) running or stopped in the background of your current 
      shell session.
    - if we run any command in background using & operator, we can see them in jobs

kill:
    - kill command is used to send signals to processes.
    - mostly it is used to terminate a running process, but it can also pause, resume, or notify a process.

    syntax:
        kill [signal] [pid]

    example:

    # SIGTERM: signal 15 
    # signal to terminate process gracefully
    # Save data.
    # Close open files.
    # Release resources.
    # Perform cleanup operations.
    kill 1234

    # SIGHUP: 1, hangup
    # SIGINT: 2, Interrupt
    # SIGQUIT: 3, quit
    # SIGKILL: 9, forcefully terminate
    # SIGTERM: 15, gracefully terminate
    # SIGCONT: 18*, continue stopped process
    # SIGSTOP: 19*, Stop process
    # SIGTSTP: 20*, Terminal stop (Ctrl+Z)
    kill -9 1234

    ctrl + c:
        - it produce SIGINT 2 signal

id : displays user and group identification information for the current user or a 
     specified user.

    id  # shows user id-name, group-id name and all the groups user belongs to
    id -u   # shows the user id of current user
    id -u john # shows the user id of john
    id -g      # shows the primary group id
    id -G      # show all the groups id

    id -un      # Show username instead of UID
    id -gn      # Show group name instead of GID
    id -Gn      # Show all group names

    # read about more option available

top:
    - used to monitor running processes and system resource usage in real time.
    - it shows
        - which processes are currently running 
        - which process consumes more cpu
        - which process consumes more RAM
        - How much CPU and memory are available
        - System load and uptime.
        - Process IDs (PIDs) and users running processes.

    Monitor single process:
        top -p [pid]
